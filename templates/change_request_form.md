# Change Request — CR-###

| Field | Entry |
|---|---|
| CR ID and date raised | CR-### (assigned by the Change and Configuration Manager); dd/mm/yyyy |
| Requested by | Name, role, department |
| Description of change | |
| Reason and benefit | |
| WBS elements affected | e.g. 1.4.3, M5 |
| Impact: scope | Deliverables added, removed or changed |
| Impact: schedule | Working days; milestones moved; effect on the critical path |
| Impact: cost | AUD; funding source (contingency, management reserve, new funds) |
| Impact: quality and risk | Effect on acceptance criteria; new or changed risks (IDs) |
| Urgency | Normal / urgent / emergency |
| Recommendation | Project manager's recommendation and options considered |
| Decision | Approved / rejected / deferred, with reason; approver name and date |
| Implementation | Owner; GitHub branch (`cr-###`) and baseline tag; Jira card |

**Approval limits:** Project Manager ≤ 5 days and ≤ AUD 10,000 with no scope change ·
Change Control Board ≤ 15 days, ≤ AUD 50,000 or any scope change · Sponsor above that,
any milestone date or the budget ceiling.
